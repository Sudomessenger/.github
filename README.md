# Sudomessenger/.github

Organization profile and shared GitHub configuration for [Sudo App](https://github.com/Sudomessenger).

## Organization profile

The public landing content on [github.com/Sudomessenger](https://github.com/Sudomessenger) is rendered from [`profile/README.md`](./profile/README.md).

To update the org homepage:

1. Edit `profile/README.md` and assets under `profile/assets/`
2. Merge to `main`
3. Refresh the organization Overview tab

## Assets

| File | Purpose |
| --- | --- |
| `profile/assets/banner.svg` | Hero banner on the org profile |
| `profile/assets/sudo-logo.svg` | Sudo mark (blue gradient) |
| `profile/assets/sudo-logo.png` | Raster logo fallback |
